## Register decisions
- Address: रउआ / राउर throughout (privacy page: "राउर पसंद", "रउआ जे चीज टिक कइले बानी"); never आप/आपका.
- "page" = पन्ना (Shubhvela UI), "website" = साइट, "record" = अभिलेख (shared tatsama with Hindi), "procedure" = विधि, "checklist" = सामान-सूची (UI spelling) in the privacy page but सामग्री के सूची in About where the glossary term [[samagri]] is marked (display सामग्री, folk सामान in brackets).
- "automatically" = खुदे (rejected अपने-आप / आपे-आप — both contain the hard tokens अपने / आप).
- "if you see a mistake" = कवनो भूल लउके (लउकल = to be seen; rejected देखाव).
- "the grihya-sutra itself says" = गृह्यसूत्र खुदे कहेला (rejected अपने कहेला — hard token).
- Emphatic ही avoided: साइटे पर, लिंके, थीमे (the Bhojpuri -े emphatic) instead of साइट पर ही etc.
- Nukta: none except ड़/ढ़ — आवाज, ऑफलाइन, फॉन्ट, ब्राउजर, तारीख, डिजिटल, फाउंडेशन (Hindi has आवाज़, ऑफ़लाइन, फ़ॉन्ट, ब्राउज़र, तारीख़).
- ण → न in everyday words: प्रमान, उच्चारन, गनना, संस्करन, सारनी, प्रकरन, उदाहरन, प्रमानपत्र, प्रशिक्षन, पौरानिक; ण kept in deity/shastric/mantra words: गणेश, सत्यनारायण, पुराण only inside book titles, तर्पण, निर्णय (press name), प्राणायाम, नामकरण, चूड़ाकरण, रामचरितमानस, पाणिनि.
- Months/weekdays per Shubhvela: असाढ़, कातिक, पूस, फागुन, भादो, आसिन, अगहन, चइत, बइसाख, जेठ; एतवार, सोमार, बुध, बियफे, सुक. Nakshatra सतभिखा, उत्तरभाद्रपदा as in Shubhvela's bho rules corpus.
- Honorific plural for the pandit and institutions: पंडित जी … देखेलन / करेलन; मालिक पढ़ेलन.
- "odd year" = बिजोर साल; "fourth month" = चउथा महीना; "first grain" = पहिला अन्न; "sight of the Sun" = सूरज के दरसन; "eleventh/twelfth day" = एगारहवाँ-बारहवाँ दिन.
- Sanskrit sutra quotations kept verbatim where they contain no Hindi-form tokens (PGS 1.4.5, 1.17.5, 1.19.1, 2.1.1–2); PGS 1.17.1 (contains the soft token नाम) paraphrased in Bhojpuri instead of quoted.
- Book titles kept as printed in Hindi (विवाह-संस्कार-पद्धति, सत्यनारायण व्रत कथा, विवाह संस्कार पद्धति (द्विवेदी)) inside links — this produces the one soft-list FLAG below; a Bhojpuri respelling would misname the books.
- The storage keys of the privacy page (pb-theme …) are shown as links to the public source folder so that the Latin tokens stay out of Bhojpuri prose; the same pattern is used in hi and en for parity.

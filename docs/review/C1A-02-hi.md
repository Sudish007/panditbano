## Register decisions
- Anusvara everywhere in Hindi prose (संकल्प, पंडित, मन्वंतर, जंबूद्वीप, भरतखंड, चंद्र, सकुटुंब) — including quoted Sanskrit incipits in prose, because the gate (G10) treats every hi field alike; the Sanskrit fields keep the conjuncts.
- पंडित (not पंडित जी) in neutral prose, पंडित जी only inside the spoken lines — the R5 §7 item 8 question stays open.
- यजमान kept (R5 fallback); पुरोहित for the role, पंडित for the person.
- मृत्यु / जन्म / अशौच / सूतक / पातक as tatsama; "शोक-संतप्त" for the bereaved.
- नुक़्ता: ज़रूरत, ज़्यादा, ज़मीन, फ़ोन, तारीख़ (Shubhvela spelling); none elsewhere.
- Health words kept neutral (चिकित्सक, स्वास्थ्य) and only in the "families decide / doctor's question" sentences.
- 'देश (राज्य)' used for the sankalpa's देश slot so the reader does not confuse it with the country.

## Unsure about
- दक्षिणा 'की बात' vs 'का उल्लेख' register — slightly colloquial on purpose.
- 'शिष्टाचार-पुस्तिका' as the F16 title (prd wording) vs 'पंडित का व्यवहार' — owner's choice.
- 'पातक' — the Hindi belt also says 'पातक/मरनी'; only पातक used.
- Transliteration of modern names in the worked example (रामप्रसाद शर्मा, वाराणसी) — fine?
